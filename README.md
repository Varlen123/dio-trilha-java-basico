## 🗂️ Estrutura do Repositório

A estrutura do repositório é a seguinte:

```

dio-trilha-java-basico/
├── tipos-variaveis/
│   ├── Condicionais/
│   ├── Repeticoes/
│   └── Excecoes/
├── README.md
```

* **tipos-variaveis/**: Contém exercícios relacionados a tipos de variáveis, estruturas condicionais, laços de repetição e tratamento de exceções.

  * **Condicionais/**: Exercícios que exploram o uso de estruturas condicionais como `if`, `else` e operadores ternários.
  * **Repeticoes/**: Exercícios que abordam laços de repetição como `while`, `for` e o uso do comando `continue`.
  * **Excecoes/**: Exercícios que tratam do uso de blocos `try-catch` para tratamento de exceções e erros.([GitHub][1])

---

## 🔍 Conteúdo Abordado

### 📄 Tipos de Variáveis

Os exercícios nesta seção abordam:

* Declaração e inicialização de variáveis de diferentes tipos primitivos em Java.
* Conversão entre tipos de dados (casting).
* Boas práticas na nomenclatura de variáveis.

### 📄 Estruturas Condicionais

Nesta seção, são explorados:

* Uso de estruturas `if`, `else if` e `else` para controle de fluxo.
* Aplicação de operadores lógicos e relacionais.
* Implementação de decisões utilizando operadores ternários.

### 📄 Laços de Repetição

Os exercícios focam em:

* Implementação de laços `for`, `while` e `do-while`.
* Controle de fluxo dentro dos laços utilizando `break` e `continue`.
* Criação de estruturas de repetição aninhadas.
